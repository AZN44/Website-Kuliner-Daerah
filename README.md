# Kuliner Nusantara - Website Kuliner Daerah

Aplikasi web yang menyajikan katalog makanan dan minuman khas dari berbagai daerah di Indonesia.

## Fitur Utama

* **Katalog Kuliner:** Penjelajahan hidangan khas berdasarkan provinsi dan daerah asal.
* **Pencarian & Filter:** Pencarian menu berdasarkan nama makanan, bahan utama, atau wilayah.
* **Detail Informasi:** Penjelasan asal-usul, resep dasar, dan ciri khas rasa.
* **Tampilan Responsif:** Desain yang menyesuaikan layar ponsel maupun komputer.

## Teknologi yang Digunakan

* HTML5 & CSS3
* JavaScript
* Tailwind CSS / Bootstrap
